# ios-projects

Misc iOS tinkering, mostly driven from Claude Code phone sessions — Widgy widgets, Shortcuts, and other small projects.

## Layout

| Folder | What it is |
|---|---|
| `widgy/` | [Widgy](https://apps.apple.com/us/app/id1524540481) widget projects — `.widgy` exports (JSON) versioned here, edited in sessions, re-imported on device |

## Workflow

Each project keeps its own folder with a README describing current state, so any future session (or human) can pick up where the last one left off. Feature work lands via branches + PRs; small setup commits go straight to `main`.
